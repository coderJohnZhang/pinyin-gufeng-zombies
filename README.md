# 拼音古风大战僵尸

一款面向小朋友的塔防小游戏。用拼音和古风文字「拼读」「答题」，答对了就发射豌豆、消灭僵尸。

## 怎么玩

在电脑或平板的浏览器中打开以下网址即可游玩，无需安装：

https://coderJohnZhang.github.io/pinyin-gufeng-zombies/

## 玩法

- **拼音关**：点击僵尸锁定它，再依次点击蓝色的声母、红色的韵母，拼出僵尸头顶的读音。第三关还需要选择声调。
- **古风关**：僵尸头顶的句子缺了一个字（显示为「□」），从 4 个选项中选出正确的字。
- 种植物需要阳光：向日葵产阳光，豌豆射手自动射击，坚果墙阻挡僵尸。
- 连续答对三次，获得一次「合体大炮」，可以清空整个草坪。
- 通关后按剩余生命评星。进度保存在当前浏览器中。

## 操作方法

| 设备 | 操作 |
| --- | --- |
| 鼠标 / 触屏 | 点击植物卡选择植物，再点击草坪种下；点击僵尸锁定；点击卡片作答 |
| 键盘 | `Q` / `W` / `E` 选择植物；`1`–`4` 选择选项或声调；空格释放合体大炮；`Esc` 暂停 |

图鉴中可以查看声母、韵母、声调的示例，以及成语释义和古诗，点击卡片可以听发音（需要设备支持中文语音）。
